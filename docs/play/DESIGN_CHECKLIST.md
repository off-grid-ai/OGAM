# Design checklist (every screenshot)

Each device screenshot is scored against these, item by item, before it goes in the ledger. Source:
`ui-library/docs/direction/DESIGN_PHILOSOPHY.md`, plus desktop's live page pattern. A screenshot passes
only when every item is a pass or a stated, accepted exception.

| # | Check | Pass when |
|---|---|---|
| 1 | Alive | The living field (dot lattice, breathing light) is behind the page; presses give way. |
| 2 | Layered depth | Surfaces are translucent over the field with a hairline edge; no hard or dark shadows. |
| 3 | One emerald | Emerald marks only the one main action, the active place and live state; everything else is the monochrome hierarchy. No colour-coded information. |
| 4 | Main action | The main action is a compact pill beside the page title (desktop's "+ New entry"), not a full-width slab. |
| 5 | Page header | Mono kicker, large regular title, grey line under it; chrome (icons) is plain, not boxed or circled. |
| 6 | Type | Geist for reading text and titles; Geist Mono only for labels, numbers, times. Weights 300–500. |
| 7 | Lists | One surface divided by hairlines; rows 40–52 px; title with meta inline; one trailing action. |
| 8 | No boxes | No stack of bordered boxes, no boxes inside boxes; a name, size and state are a row, not a card. |
| 9 | Icons over labels | Row actions are icon buttons with an accessible name; words only for calls to action. |
| 10 | Tokens | Colours, sizes and timings come from `@offgrid/design`; no hard-coded hex in components. |
| 11 | Accessible | Text 4.5:1, targets 44 px, icon buttons named. |
| 12 | Same family | Side by side with desktop's page, it reads as the same product. |
